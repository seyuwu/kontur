# Бесплатная облачная LLM для демо

Проверено по официальным источникам: **2026-10-21**.

Выбран **Groq Free**, модель **`openai/gpt-oss-20b`**, для извлечения фактов из синтетических русских медицинских документов в демо. Требуется аккаунт Groq и API-ключ; обучение модели не требуется. Локальные загрузки и запуск моделей пользователь отклонил. [Groq Quickstart: API-ключ](https://console.groq.com/docs/quickstart), [поддерживаемая модель и structured output](https://console.groq.com/docs/structured-outputs).

## Реализация в приложении

Адаптер Groq разрешён **только при `DEMO_MODE=true`**; автоматического переключения на OpenAI нет. Ключ `GROQ_API_KEY` хранится на сервере. Приложение ограничивает исходный текст **8,000 символами**, ответ — **2,048 токенами**, и отклоняет усечённый ответ. Это ограничения приложения для снижения расхода бесплатной квоты, **не размер контекстного окна провайдера**. Символы и токены не равнозначны; эти пределы не гарантируют попадания каждого запроса в свободную квоту с учётом схемы, инструкций и остальных запросов.

На момент записи рабочего API-ключа нет, реальный запрос к Groq не выполнен. Проверено **59 тестов с подменёнными ответами**; это не проверка доступности сервиса, реальной точности модели или клиническая валидация.

## Данные и границы демо

Groq не вправе использовать inputs/outputs для обучения без разрешения клиента. По умолчанию inference-данные не сохраняются, но возможны логи надёжности/abuse до 30 дней; доступна настройка Zero Data Retention. Сохраняемые данные находятся в США. [Services Agreement §4.2](https://console.groq.com/docs/legal/services-agreement), [Your Data](https://console.groq.com/docs/your-data).

**BAA §1.1 исключает бесплатные услуги из Covered Cloud Services.** Бесплатный API не следует считать согласованным контуром для идентифицируемых медицинских данных. Для этого демо использовать синтетические документы; отсутствие обучения и наличие ZDR сами по себе не разрешают отправку реальных данных пациентов. [Groq Business Associate Addendum](https://console.groq.com/docs/legal/customer-business-associate-addendum).

Контракт извлечения: только явно содержащиеся в документе факты, `null`/пустой список для неизвестного по схеме, цитаты-основания для результата. До оценки качества на контролируемых русских примерах нельзя утверждать, что модель правильно различает отрицания, анамнез и текущее состояние, дозы, единицы и даты.
