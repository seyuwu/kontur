# Уведомления и рекомендации по результатам анкет

В учебном контуре опубликованы версии 2 восьми бланков F40. После отправки новой анкеты создаётся одно событие с рекомендацией для врача. Черновик не создаёт событие. Повтор того же запроса не создаёт новое событие. Результаты анкет не создают внешние push/email; актуальное правило — только просьбы пациента связаться (обновление от 24 октября). Если одновременно с диапазоном SCL-90-R сработал ответ о безопасности, остаётся одно событие по этому ответу.

## Когда приходит уведомление

| Бланк | Диапазоны и сценарии |
| --- | --- |
| BAI | 0–9 — плановый разбор; 10–21 — уточнить симптомы; 22–35 — обсудить состояние; 36–63 — высокий показатель, разбор и контакт |
| HAM-A, заполняет врач | 0–7 — плановый разбор; 8–17 — уточнить симптомы; 18–24 — обсудить состояние; 25–56 — высокий показатель, разбор и контакт |
| SPRAS | 0–29 — плановый разбор; 30–79 — обсудить состояние; 80–140 — высокий показатель, разбор и контакт |
| BFNE | 12–23 — плановый разбор; 24–46 — уточнить социальную тревогу; 47–60 — высокий показатель, разбор и контакт |
| ИТТ СТ-С / СТ-Л | Результат без категории. Сырые суммы не превращаются в «хорошо/плохо»: взвешенные подшкалы и нормативы не перенесены |
| GELOPH-15 | Результат без категории: в диапазонах среднего значения PDF есть промежутки |
| SCL-90-R | Результат без категории: описательные нормативы не превращаются в универсальный порог. Любой ненулевой ответ на пункт 15 создаёт отдельное событие для уточнения безопасности вместо общего события |

Числовые диапазоны взяты из соответствующих приложений предоставленного PDF. **Решение создать уведомление и порядок его разбора — организационные правила приложения, требующие согласования с клиническим экспертом.** Это не утверждение, что рекомендации предписывают отправлять push при конкретном балле.

## Что видит врач

В списке событий указаны инструмент, диапазон и категория рабочего процесса. Сначала показываются события для уточнения безопасности, затем высокие показатели, результаты для разбора и плановые результаты. Этот порядок не является клинической шкалой срочности.

Внутри события видны балл, исходные ответы, период, конкретная рекомендация врачу и документы-основания. Для каждой предложенной операции доступны пояснение и ссылки. Врач может сверить ответы и план, согласовать контакт и зафиксировать собственное решение. Открытие чата не считается выполненным контактом.

- Для низкого показателя предлагается сверить жалобы, ответы, план и дату следующего контакта. Приложение не утверждает, что пациент здоров, и не отменяет наблюдение.
- Для промежуточного показателя предлагается уточнить симптомы, избегание и влияние на жизнь, сравнить с предыдущей оценкой той же методики и согласовать дальнейшее наблюдение.
- Для высокого показателя предлагается контакт и клиническая оценка актуального состояния, ограничений, сопутствующих состояний и переносимости терапии. Решение о консультации и маршруте помощи принимает врач.
- Для ответа SCL-90-R о мыслях о самоубийстве предлагаются контакт, уточнение актуального состояния и отдельная клиническая оценка безопасности. Ответ относится к периоду анкеты и сам по себе не устанавливает текущие намерения или опасность. Страх смерти в BAI не вызывает такой сигнал.

Рекомендации программные, закреплены версией анкеты и работают без Groq. LLM при доступном провайдере может помочь обобщить основания, но не меняет баллы, категорию уведомления или список доступных действий.

## Документы

- Предоставленные КР «Тревожно-фобические расстройства», ID 455, 2024: приложения Г1, Г2, Г3, Г5, Г6, Г17, Г18; раздел 2.1 (PDF стр. 14–15), 2.5 (стр. 20), 6 (стр. 45). PDF доступен авторизованному пользователю из события. Актуальность редакции и применимость цифрового переноса требуют клинической проверки.
- [NICE CG159](https://www.nice.org.uk/Guidance/CG159/chapter/recommendations#assessment-of-adults-with-possible-social-anxiety-disorder), 1.2.4–1.2.8 — дополнительный контекст для оценки возможной социальной тревоги у взрослых. Это не источник порогов BFNE.
- [NICE NG225](https://www.nice.org.uk/guidance/ng225/chapter/Recommendations#risk-assessment-tools-and-scales), 1.6.1–1.6.6 — ограничения использования шкал для прогнозирования суицида и выбора доступа к помощи, индивидуальная оценка потребностей и безопасности.

## Push и проверка

После обновления от 24 октября 2026 результаты анкет и рекомендации остаются в кабинете, без внешнего push или email. Push приходит только по отдельной просьбе пациента связаться; тестовая отправка из настроек доступна отдельно. Старые ожидающие отправки по анкетам отменяются. [Актуальные сценарии проверки, приёмы и Mistral](updates-2026-10-24.md).

Чтобы сравнить рекомендации, назначьте новую BAI версии 2 и отправьте ответы с суммой 0, затем следующее назначение с суммой от 36 до 63. В каждом случае создаётся одно событие в кабинете, с разными рекомендациями и источниками. Назначения версии 1 сохраняют прежние правила и не переписываются.
